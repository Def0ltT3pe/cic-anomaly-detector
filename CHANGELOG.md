# Changelog

## [Unreleased]

### Added

  и уведомления в Telegram о каждом новом инциденте (сводка, если их больше

  места и запуск сбора, сервер попадает в `pull_captures.json`; статус,
  остановка и удаление уже добавленных.
- Статистика сервера во вкладке «Мониторинг»: потоки и тревоги по часам,
  доля тревог, атакующие адреса и порты, последнее скачивание; состояние
  сбора с сервера (место, объём, темп, сколько файл живёт в кольце);
  сравнение серверов за сутки.

## [2.0.0] - 2026-11-03

Детектор научился работать с собственными захватами: pcap загружается прямо
в приложение, модели адаптируются под свою сеть, срабатывания сводятся в
инциденты, а любой поток можно разобрать вместе с ИИ. Интерфейс разбит на
вкладки и получил собственную тему. Версия мажорная из-за изменений в
развёртывании и проверке моделей — см. «Breaking changes».

### Breaking changes

- Docker: без `config/users.json` и `APP_PASSWORD` приложение больше не
  открывается в режиме `anonymous/admin`, а показывает, как настроить вход
  (`ALLOW_OPEN_MODE=0` в образе; `ALLOW_OPEN_MODE=1` возвращает старое
  поведение). Локальный запуск не изменился.
- Docker: порт по умолчанию публикуется на `127.0.0.1`; для доступа по сети
  задайте `APP_BIND=0.0.0.0`.
- Если есть публичный ключ (`trust/model_public_key.pem`), папка модели без
  `checksums.json` не загружается. Подпишите модели (`python make_checksums.py`)
  или временно задайте `ALLOW_UNSIGNED_MODELS=1`.

### Added

- `pcap_to_flows.py`: pcap/pcapng → признаки CICFlowMeter через tshark,
  потоковая обработка больших захватов; загрузка pcap прямо в приложении и
  выгрузка потоков в Parquet.
- Сбор данных на серверах: `collect_capture.sh` (захват с контролем диска и
  журналом sshd) и `pull_captures.ps1` (скачивание сессий на Windows по
  расписанию).
- `label_from_authlog.py`: разметка SSH-потоков по журналу sshd, включая
  соединения со стороны сервера.
- `adapt_model.py`: дообучение и калибровка моделей на своей сети;
  `evaluate.py`: проверка «обучили на одной сети — проверили на другой» и на
  отложенных файлах.
- `build_flagship.py` и модель `models_flagship`: одна модель, обученная на
  всех сетях.
- Выбор модели в боковой панели: подписанные папки `models*` и `MODELS_ROOT`,
  карточка модели с качеством на проверке.
- Инциденты: срабатывания классификатора сводятся по внешнему адресу за час;
  `TRUSTED_IPS` исключает свои адреса и подсети.
- Разбор любого потока: факты моделей, график отличий от нормы, вердикт,
  отчёт ИИ с уточняющими вопросами и выгрузка в Markdown. Адреса для ИИ
  маскируются, данные из файла не исполняются как инструкции.
- ИИ на выбор: Gemini, Claude, ChatGPT, DeepSeek, OpenRouter и свои варианты
  из `config/llm.json` (Ollama, LM Studio); ключ можно ввести в интерфейсе на
  время сессии.
- Вкладки «Обзор», «Инциденты», «Потоки», «Разбор потока»; графики тревог по
  времени и топ-адресов/портов, клик по строке таблицы открывает разбор.

### Changed

- Своя тема для светлого и тёмного режима (шрифты Golos Text и JetBrains
  Mono), шапка, переключатель разделов, карточки показателей в рамках,
  боковая панель из блоков «Модель», «ИИ», «Аккаунт». Меню Deploy скрыто.
- Gemini вызывается по HTTP без SDK `google-genai`.
- Модели сохраняются сжатыми; RandomForest в `adapt_model.py` глубже.
- Ключ подписи моделей заменён, модели переподписаны.

### Fixed

- Калибровка порога и обработка NaN; конфиги модели (`calibration.json`,
  `normal_stats.json`) проверяются по подписи.
- Перекалибровка без меток больше не снижает порог supervised-модели.
- Загрузка pcap вместе с CSV, где время записано текстом, больше не падает
  при выгрузке потоков в Parquet.

### Security

- Подпись моделей нельзя обойти удалением `checksums.json`.
- Блокировка после 5 неверных паролей действует для логина во всех сессиях;
  раньше её сбрасывала перезагрузка страницы.
- `pull_captures.ps1` не пишет файлы за пределы своей папки, даже если
  сервер прислал путь с `..`.
- В Docker-образе код и модели доступны процессу приложения только на
  чтение; записывать он может лишь в `audit/`.

### Known limitations

- Блокировка входа хранится в памяти процесса и привязана к логину, не к IP.
- Модели обучены на CIC-IDS и собственных захватах; для новой сети нужна
  адаптация (`adapt_model.py`).
- Нет MFA/SSO и ротации журнала аудита.

## [1.0.0] - 2026-10-19

Первый публичный релиз. Проект основан на ранее написанном
[Practik-2](https://github.com/Def0ltT3pe/Practik-2): оттуда взяты
подготовка CIC-IDS2017, исходная модель IsolationForest и первые версии
Streamlit/CLI. В этой версии пайплайн переработан и дополнен.

### Added

- Гибридная детекция: IsolationForest для общих аномалий и supervised
  RandomForest для BruteForce.
- Калибровка порога по benign-трафику (`calibration.json`, целевой FPR 2%),
  score и percentile в UI/CLI.
- Веб-интерфейс Streamlit: загрузка CSV/Parquet, метрики, таблицы аномалий,
  пояснения Gemini.
- CLI `detector.py` с отчётом, `--use_llm`, `--model-dir`.
- Пользователи и роли (`admin`/`analyst`/`viewer`), PBKDF2, блокировка
  после 5 неудачных попыток.
- Журнал аудита JSONL (`audit/audit.jsonl`) с санитайзингом секретов.
- Подпись моделей Ed25519 (`checksums.json`), проверка при загрузке.
- Dockerfile (non-root, healthcheck) и docker-compose.
- Тесты на `unittest`, CI GitHub Actions.

### Fixed

- Пути к моделям и статистикам больше не зависят от текущего каталога.
- `inf`/`NaN`/текстовые значения и пустые файлы обрабатываются с понятными
  ошибками, а не трейсбеками.
- Убран обязательный тренировочный parquet: статистики лежат в JSON.
- Исправлен `CMD` Docker (`App.py`), добавлен `pyarrow`.
- Состояние анализа сбрасывается при загрузке нового файла.
- `detector.py` больше не пишет отчёт в `~/Desktop` и не падает без LLM.

### Security

- Удалены захардкоженные ключи Gemini; ключ читается из `GEMINI_API_KEY`
  или `.streamlit/secrets.toml`.
- Добавлены `.gitignore`/`.dockerignore`, приватный ключ подписи не
  попадает в репозиторий и образ.
- Модели проверяются по SHA-256 и Ed25519-подписи.
- Пароли не хранятся в открытом виде; аудит не пишет секреты.

### Known limitations

- BruteForce-модель обучена на CICIDS Tuesday; для другой сети нужно
  переобучение на размеченных данных.
- Нет MFA/SSO и ротации журнала аудита.
- Подпись Ed25519 хранится на хосте, не в HSM.
